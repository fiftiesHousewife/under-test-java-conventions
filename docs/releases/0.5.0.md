## What changed since 0.4.0

* **A repo can list each test's result in a quiet build.** With `underTest.listEachTest = true`, every test task shows each test as passed, failed or skipped even in a quiet build (`--quiet`), as a recording uses, a failure with its message and no stack trace ([record 0035](https://github.com/fiftiesHousewife/under-test-java-conventions/blob/main/docs/decisions/0035-a-repo-can-list-each-tests-result-in-a-quiet-build.md)).
* **Code testing how Mockito attaches itself can leave out Mockito's agent.** With `underTest.mockitoAgent = false`, no test JVM starts with Mockito's agent, and Mockito attaches it itself as it runs ([record 0036](https://github.com/fiftiesHousewife/under-test-java-conventions/blob/main/docs/decisions/0036-code-testing-how-mockito-attaches-itself-can-leave-out-mockitos-agent.md)).

Moving from 0.4.0: nothing changes unless a repo sets one of the two new settings.
