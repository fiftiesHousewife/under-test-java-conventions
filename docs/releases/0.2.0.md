## What changed since 0.1.0

* **Code kept below the standards on purpose can be left out.** `underTest.codeStyleExcludes` takes Ant-style path patterns from the source folder, such as `**/legacy/**` or `**/*WeakTest.java`. Checkstyle, PMD, the copy-paste and package-size checks, SpotBugs and forbidden APIs leave those files out; the compiler, the tests and coverage still see them ([record 0026](https://github.com/fiftiesHousewife/under-test-java-conventions/blob/main/docs/decisions/0026-code-kept-below-the-standards-on-purpose-can-be-left-out-of-the-code-quality-checks.md)).
* **Test libraries' own assertion calls count.** A test whose only check is REST Assured's `then()`, ArchUnit's `check(...)`, Awaitility's `until...(...)` or jetCheck's `shouldHold(...)` no longer fails TestMustAssert ([record 0027](https://github.com/fiftiesHousewife/under-test-java-conventions/blob/main/docs/decisions/0027-a-test-librarys-own-assertion-call-counts-as-the-tests-assertion.md)).
* **A repo can require a minimum mutation score.** With `underTest.minMutationScore`, `pitest` fails when the tests catch fewer of the planted bugs than that percentage; unset, nothing changes ([record 0025](https://github.com/fiftiesHousewife/under-test-java-conventions/blob/main/docs/decisions/0025-a-repo-can-require-a-minimum-mutation-score.md)).
* **Builds for an older Java compile.** javac's warnings about its own flags, such as "source value 8 is obsolete" with `options.release = 8`, no longer fail the build ([record 0024](https://github.com/fiftiesHousewife/under-test-java-conventions/blob/main/docs/decisions/0024-compiling-for-an-older-java-is-not-a-warning-that-fails-the-build.md)).

Nothing that passed on 0.1.0 fails on 0.2.0.
