## What changed since 0.5.0

* **Fixed:** when a test ends the test JVM, as with `System.exit`, the run still ends in one line, counting the tests that reported ("1 of 2 tests passed; 1 didn't run."). The summary used to depend on the test task, so Gradle skipped it when that task failed ([record 0032](https://github.com/fiftiesHousewife/under-test-java-conventions/blob/main/docs/decisions/0032-a-test-run-ends-in-one-line-naming-its-report-by-a-path-from-the-project.md)).

Moving from 0.5.0: nothing to change.
